# URL tracker

Консольный скрипт для измерения скорости скачивания по заданному URL. Выполняет 10 запросов последовательно и ждёт полного получения тела каждого ответа.

## Запуск

Нужен Node.js 18 или новее. Зависимости устанавливать не требуется.

```bash
node index.js "https://example.com/large-image.jpg"
```

Скрипт выводит время и размер каждого ответа, среднее время запроса, общий объём и скорость скачивания. Скорость указана в **МБ/с**: 1 МБ = 1 000 000 байт. Она вычисляется как сумма байт тел ответов, делённая на суммарное время всех 10 запросов. Время включает ожидание ответа и перенаправления. HTTP-заголовки в объём не входят.

При сетевой ошибке, ответе вне диапазона HTTP 2xx или отсутствии сетевой активности более 60 секунд скрипт завершится с ошибкой.
